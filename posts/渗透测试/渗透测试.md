为了探测内网，下载

```bash
wget https://gh-proxy.org/https://github.com/shmilylty/netspy/releases/download/v0.0.5/netspy_linux_amd64.zip
apt install unzip   #debian系
unzip netspy_linux_amd64.zip
./netspy -c 0.0.0.0/0 #扫描内网网段，可以事先用ip a查看
```
